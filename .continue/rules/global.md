# Overseer Global Project Guidelines

## Project Context

Overseer is a utility for monitoring multiple 3D printers (OctoPrint, RepRapFirmware, Elegoo, Bambu Labs) from a single interface.

## Coding Standards

- Maintain strict separation of concerns.
- All code must be compatible with the AGPL-3.0 license.
- Prioritize clean, readable code over clever one-liners.
- Write clear, concise comments only for complex logic. Avoid stating the obvious.
- Ensure cross-platform compatibility where applicable.

## AI Instructions

- Provide straightforward, direct answers.
- Do not use any analogies when explaining technical concepts, architecture, or code execution.
- Only provide the modified code blocks when refactoring, rather than rewriting the entire file.
